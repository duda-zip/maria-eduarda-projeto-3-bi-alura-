# Alura Plus — Página de Apresentação

Projeto de frontend de uma página promocional do Alura Plus, com destaque para o Combo+, oferta que reúne Alura+ e Alura Língua.

## Sobre o projeto
A página apresenta os benefícios dos serviços, opções de assinatura e dispositivos compatíveis. O objetivo é praticar a construção e a estilização de uma landing page utilizando HTML e CSS.

## Seções da página
- Apresentação do Combo+ e chamadas para assinatura.
- Divulgação do acesso em diferentes dispositivos.
- Apresentação da combinação de cursos de tecnologia e idiomas.
- Seção informativa sobre download de cursos.
- Lista de dispositivos: TV, computador e celular.
- Rodapé com links institucionais e informações sobre o serviço.

## Tecnologias utilizadas
- **HTML5:** estrutura e conteúdo.
- **CSS3:** estilos, cores, espaçamento e efeitos de interação.
- **CSS Grid:** organização das seções em duas colunas.
- **Flexbox:** alinhamento das listas de dispositivos e links.
- **Google Fonts:** fonte Inter.

## Organização dos arquivos
- `index.html`: estrutura da página.
- `style.css`: estilos e organização do layout.
- Arquivos `.png`: imagens promocionais, logotipo e ícones.

## Como executar
1. Baixe e extraia o projeto.
2. No `index.html`, altere a referência de `styles.css` para `style.css`.
3. Crie uma pasta chamada `img` e mova todos os arquivos PNG para ela.
4. Atualize os links de assinatura de `www.alura.com.br` para `https://www.alura.com.br`.
5. Abra `index.html` no navegador.

Não é necessário instalar dependências. O carregamento da fonte Inter utiliza conexão com a internet.

## Status e limitações
Projeto estático de interface, sem JavaScript, backend ou banco de dados.
As seções apresentam funcionalidades dos serviços divulgados; a página não realiza compras, cadastro de usuários, reprodução de aulas ou download de cursos. Os links do rodapé utilizam destinos provisórios.
O layout utiliza duas colunas e não possui media queries para adaptação específica a celulares, podendo precisar de ajustes em telas menores.
Os preços e as condições exibidos fazem parte do conteúdo do projeto e não devem ser considerados uma oferta atual.

## Aprendizados
Prática de estruturação com HTML, variáveis CSS, Grid, Flexbox, imagens de fundo, tipografia e efeitos de interação com `hover` e `active`.
